2. Loop while True terus meminta input sampai user ketik selesai, dengan pengecekan minimal 5 data dan harus ada minimal 1 nilai lulus + 1 remedi sebelum boleh berhenti.
3. Fitur hapus memungkinkan dosen menghapus nilai yang salah input — dicari dulu di nilai_masuk, lalu dihapus juga dari lulus/remedi kalau ada di sana.
4. Percabangan if/else pada bagian pengelompokan membandingkan nilai dengan batas_nilai[0] (indeks 0 dari tuple = batas lulus).
5. try/except dipakai untuk menangani input yang bukan angka (validasi sederhana).
